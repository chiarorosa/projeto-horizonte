# frontend/

Páginas, componentes, navegação, dashboards, gamificação e experiência do usuário do Projeto Horizonte.

- Pode usar **dados simulados (mocks)** até que a API esteja disponível, desde que sigam os formatos de [`../contracts/`](../contracts/).
- Instruções de execução e testes ficam em [`../docs/DEVELOPMENT.md`](../docs/DEVELOPMENT.md).

> A stack (framework, gerenciador de pacotes e bibliotecas de UI) será definida em Issue própria e registrada em [`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md).
