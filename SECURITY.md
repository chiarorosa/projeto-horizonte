# Política de segurança

## Como reportar uma vulnerabilidade

**Não abra uma Issue pública** para falhas de segurança nem para dados pessoais expostos.

Use o reporte privado do GitHub: aba **Security** → **Report a vulnerability** ([link direto](https://github.com/chiarorosa/projeto-horizonte/security/advisories/new)). Só os responsáveis pelo repositório veem o relato.

Inclua, se possível:

- o que foi encontrado e onde (arquivo, endpoint ou tela);
- como reproduzir;
- o impacto esperado.

## Escopo

O Horizonte é um protótipo de pesquisa. Ele trabalha só com documentos autorizados, sintéticos ou anonimizados, em conformidade com a LGPD (ver [README](README.md#sobre-o-horizonte)). Credenciais ou dados pessoais versionados por engano também devem ser reportados por este canal, e a credencial deve ser trocada de imediato.
